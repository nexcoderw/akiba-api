# Documentation

Keep essential setup, commands and operational behavior concise in the existing root README. API
contracts belong in executable Swagger/OpenAPI metadata and relevant source comments. Preserve agent
instructions. Do not create a root docs directory, architecture reports, task reviews, ADRs, runbooks
or separate security/checklist documents in this API repository unless the human explicitly asks.

Keep commands, examples, security caveats and implemented versus planned behavior accurate. Never
include real credentials, personal data or claims that unexecuted checks passed. Process liveness
never implies database readiness. Report implementation findings directly in the conversation.
